# Componentes de terceros

AeroFoam usa estas bibliotecas, cada una con su licencia:

| Componente | Uso | Licencia |
|---|---|---|
| Python | lenguaje | PSF License |
| NumPy | cálculo | BSD 3-Clause |
| Matplotlib | gráficos y vistas | Matplotlib License (basada en PSF) |
| Pillow | imágenes e icono | MIT-CMU (HPND) |
| ezdxf | lectura de DXF | MIT |
| Tcl/Tk (tkinter) | interfaz | licencia BSD de Tcl/Tk |
| PyInstaller | empaquetado del instalador | GPL 2 con excepción para programas empaquetados |
| Inno Setup | instalador de Windows | licencia de Inno Setup |

## Perfiles
Las coordenadas de los perfiles del catálogo son datos públicos de perfiles aerodinámicos publicados;
cada perfil conserva el nombre con el que lo publicó su autor. Las descripciones, categorías y datos
del catálogo los calcula AeroFoam.
